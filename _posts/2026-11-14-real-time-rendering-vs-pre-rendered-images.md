## 1. The difference

- **Pre-rendered:** the computer calculates an image or video once. High quality, fixed view.
- **Real-time:** a game-style engine draws the scene as you move. Interactive, instantly updated.

## 2. Compare

| | Pre-rendered | Real-time |
|---|---|---|
| Viewer control | None | Full |
| Change speed | Re-render | Update and view |
| Best for | Hero stills, print | Reviews, buyers, walkthroughs |
| Needs powerful device | No (images) | Optimised for phones if built well |

## 3. Which to pick

- Brochure cover, hoarding, press: pre-rendered.
- Client meeting, buyer link: real-time.
- Social clips: capture from real-time.

**What it means.** This is not either-or. Build one good model, then output the format each audience needs.

## 4. Mind the phone

A real-time scene must be optimised to run smoothly on a mid-range phone. Heavy models that look great on a workstation can stall in a browser, so ask your provider how they optimise.
