## 1. The four formats in one line each

- **3D render:** a still image. Beautiful, fixed angle.
- **Walkthrough video:** a rendered fly-through. Fixed path, costly to change.
- **360° tour:** linked panoramic photos. Needs a real, finished space.
- **Interactive 3D walkthrough:** a model the buyer walks anywhere, from a link.

## 2. Side by side

| | 3D render | Video | 360° tour | Interactive 3D |
|---|---|---|---|---|
| Works before construction | Yes | Yes | No | Yes |
| Buyer controls the path | No | No | Limited | Yes |
| Easy to change | Medium | Costly | Reshoot | Update model |
| Needs an app or headset | No | No | No | No |
| Best for | Ads, brochure | Social, launch | Ready homes | Pre-sales |

## 3. Which one for which job

- **Launching a project:** render + interactive walkthrough.
- **Social media reach:** short video cut from the model.
- **Ready or resale homes:** 360° tour.
- **Closing remote buyers:** interactive walkthrough link.

**What it means.** You rarely need all four. Most developers start with renders and an interactive walkthrough, then cut a short video from the same model.

## 4. One model, many outputs

A good 3D model is an asset. The same model can produce renders, a video and a walkthrough, so ask for the model approach, not four separate quotes.
