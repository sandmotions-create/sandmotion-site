## 1. Two kinds of twin

| | Visual twin | IoT-connected twin |
|---|---|---|
| Core | Accurate interactive 3D | 3D plus live data |
| Data needed | CAD or BIM files | Sensors, PLC/SCADA, APIs |
| Setup effort | Lower | Higher |
| Best for | Reviews, training, sales, planning | Monitoring, alerts, prediction |

## 2. Why start visual

- Everyone sees the same model.
- Maintenance, operations and management agree on what they are looking at.
- You learn which data you actually need.

## 3. Then add data

Once the model is trusted, overlay status colours, alerts and trends: steady green for nominal, amber for wear, red for critical.

## 4. A staged path

1. **Stage 1:** CAD to real-time 3D.
2. **Stage 2:** Web or engine build for browser or Unreal/Unity.
3. **Stage 3:** Data overlays and animations.
4. **Stage 4:** AR/VR training and field guides.

**What it means.** Staging reduces risk. Each stage should deliver something your team can use, not just a milestone.
